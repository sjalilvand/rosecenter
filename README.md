# 🌹 وب‌سایت مرکز خدمات روانشناسی و مشاوره رز

بازنویسی کامل وب‌سایت [rosecenter.ir](https://rosecenter.ir) با استفاده از **Python Flask** و **SQLite**

## 🛠 تکنولوژی‌ها

| لایه | تکنولوژی |
|------|----------|
| بک‌اند | Python 3.10+ / Flask 3 |
| دیتابیس | SQLite (بدون وابستگی خارجی) |
| فرانت‌اند | Jinja2 + HTML5 + CSS3 + Vanilla JS |
| طراحی | RTL فارسی، ریسپانسیو، فونت وزیرمتن |

## 🚀 راه‌اندازی

```bash
# ۱) نصب وابستگی‌ها
pip install -r requirements.txt

# ۲) ساخت دیتابیس و داده‌های اولیه
python init_db.py

# ۳) اجرای سرور
python app.py
```

سایت روی `http://localhost:5000` اجرا می‌شود.

### پنل مدیریت

- آدرس: `http://localhost:5000/admin`
- نام کاربری: `admin`
- رمز عبور: `admin123`

> ⚠️ **مهم:** بعد از اولین ورود، از بخش «تغییر رمز عبور» رمز پیش‌فرض را عوض کنید.

## ✨ امکانات

### سایت عمومی
- صفحه اصلی با هیرو، خدمات، انواع درمان، درباره ما، نظرات مراجعین، سوالات متداول و اخبار
- خدمات با دسته‌بندی (روان درمانی، مشاوره، آموزش، سایر خدمات) و صفحات جزئیات
- مراکز استانی به تفکیک استان
- **درخواست مشاوره** با تولید خودکار شماره پیگیری
- **رزرو نوبت آنلاین** (۶ نوع درمان + انتخاب تاریخ و ساعت)
- **پیگیری درخواست** با شماره پیگیری و نمایش وضعیت (تایم‌لاین)
- **درخواست همکاری** با فرم اختصاصی
- **آکادمی رز**: لیست دوره‌ها + ثبت‌نام آنلاین در دوره
- اخبار و اطلاعیه‌ها
- **پیشنهاد و انتقاد**
- تماس با ما + فرم پیام
- سوالات متداول (آکاردئون، دسته‌بندی‌شده)
- جستجو در خدمات، اخبار و دوره‌ها
- تاریخ شمسی (تبدیل خودکار میلادی به جلالی)
- کاملاً ریسپانسیو (موبایل / تبلت / دسکتاپ)

### پنل مدیریت
- داشبورد با آمار کلی (۸ شاخص)
- مدیریت درخواست‌های مشاوره، نوبت‌ها، ثبت‌نام دوره‌ها، درخواست‌های همکاری، پیشنهاد و انتقاد و پیام‌ها + تغییر وضعیت (در انتظار بررسی / در حال بررسی / تکمیل شده / رد شده) + فیلتر بر اساس وضعیت
- CRUD کامل: خدمات، اخبار، دوره‌ها، مراکز استانی، نظرات مراجعین، سوالات متداول
- تنظیمات سایت (نام، آدرس، تلفن، ایمیل، شبکه‌های اجتماعی و...)
- تغییر رمز عبور

## 📁 ساختار پروژه

```
rosecenter/
├── app.py                  # نقطه ورود

├── templates/              # قالب‌های Jinja2 (RTL)
│   ├── base.html, index.html, ...
│   └── admin/              # قالب‌های پنل مدیریت
└── static/
    ├── css/style.css       # استایل سایت
    ├── css/admin.css       # استایل پنل
    ├── js/main.js
    └── img/                # لوگو و favicon
```

## 🔐 نکات امنیتی برای استقرار (Production)

1. متغیر محیطی `SECRET_KEY` را مقداردهی کنید:
   ```bash
   export SECRET_KEY="یک-کلید-تصادفی-طولانی"
   ```
2. رمز عبور پیش‌فرض ادمین را تغییر دهید.
3. برای اجرای عملیاتی از `gunicorn` استفاده کنید:
   ```bash
   pip install gunicorn
   gunicorn -w 4 -b 0.0.0.0:8000 app:app
   ```
4. برای دامنه واقعی، HTTPS را فعال کنید.
5. مسیر `/admin` را در سرور با محدودیت IP یا لایه احراز هویت اضافی محافظت کنید.
