# وب‌سایت مرکز خدمات روانشناسی و مشاوره رز

بازنویسی کامل سایت [rosecenter.ir](https://rosecenter.ir) با **Flask (پایتون)** و دیتابیس **SQLite** — بدون وابستگی به وردپرس.

## امکانات

### بخش عمومی سایت
- صفحه اصلی با تمام بخش‌های سایت اصلی: خدمات، معرفی مرکز، انواع مشاوره، مشاوره تلفنی و آنلاین، روان‌درمانی، دریافت نوبت، آموزش، نظرات مراجعین، سوالات متداول
- صفحات خدمات: **روان درمانی**، **مشاوره**، **آموزش**، **سایر خدمات** + صفحه فهرست خدمات
- صفحه **مراکز استانی** با داده‌های واقعی ۳۱ استان (آدرس، تلفن کلینیک، مدیر، مسئول اجرایی، ساعت کاری) + جستجو
- صفحه **درخواست همکاری** با فرم کامل و صدور کد پیگیری
- صفحه **آکادمی رز** با معرفی دوره‌ها و لینک به سامانه آموزش
- سیستم **اخبار و اطلاعیه‌ها** با صفحه جزئیات خبر، صفحه‌بندی و جستجو
- صفحات **درباره ما** و **تماس با ما** (با فرم تماس)
- صفحه **درخواست مشاوره** (فرم دریافت نوبت روان‌درمانی با انتخاب نوع درمان و مرکز) + صدور کد پیگیری
- صفحه **پیگیری درخواست** با شماره پیگیری (درخواست نوبت و همکاری)
- صفحه **پیشنهاد و انتقاد** (فرم نظرسنجی/گزارش)
- **جستجوی سراسری** در خدمات، اخبار، سوالات متداول و مراکز
- کاملاً **RTL** و فارسی با فونت وزیرمتن (باندل‌شده در پروژه)
- واکنش‌گرا (Responsive) برای موبایل، تبلت و دسکتاپ + منوی موبایل
- فرم‌های محافظت‌شده با **CSRF Token**

### پنل مدیریت (`/admin/`)
- ورود امن با گذرواژه هش‌شده (PBKDF2)
- **داشبورد** با آمار کلی درخواست‌ها و آخرین موارد
- مدیریت **درخواست‌های نوبت**: جستجو، فیلتر وضعیت، تغییر وضعیت، یادداشت مدیر، حذف
- مدیریت **درخواست‌های همکاری**: جستجو، فیلتر، تغییر وضعیت، حذف
- مدیریت **پیام‌های تماس** و **پیشنهادها و انتقادها** (خوانده‌شده/نشده، حذف)
- CRUD کامل **اخبار** (ایجاد، ویرایش، انتشار/عدم انتشار، حذف)
- CRUD کامل **مراکز استانی**
- CRUD کامل **سوالات متداول** و **نظرات مراجعین**
- مدیریت **خدمات** (نمایش/مخفی، ترتیب منو)
- **تنظیمات سایت** (تلفن‌ها، آدرس، ایمیل، شبکه‌های اجتماعی، متن فوتر)
- تغییر **گذرواژه مدیر**

## نصب و اجرا

```bash
# ۱) نصب پیش‌نیازها
pip install -r requirements.txt

# ۲) ساخت دیتابیس و درج داده‌های اولیه (۳۱ مرکز استانی، اخبار، سوالات متداول و ...)
python seed_data.py

# ۳) اجرای سایت
python app.py
```

سایت روی `http://localhost:5000` اجرا می‌شود.

### ورود به پنل مدیریت
- آدرس: `http://localhost:5000/admin/login`
- نام کاربری: `admin`
- گذرواژه: `rose@1403`

> ⚠️ پس از استقرار واقعی، حتماً گذرواژه را از بخش تنظیمات پنل تغییر دهید و متغیر محیطی `SECRET_KEY` را مقداردهی کنید.

## استقرار (Deployment)

```bash
gunicorn -w 2 -b 0.0.0.0:8000 app:app
```

## ساختار پروژه

```
rosecenter/
├── app.py               # برنامه اصلی فلسک (همه مسیرها)
├── config.py            # پیکربندی و تنظیمات پیش‌فرض
├── database.py          # لایه SQLite (ساخت جداول، کوئری)
├── seed_data.py         # داده‌های اولیه (محتوای واقعی سایت)
├── requirements.txt
├── static/
│   ├── css/             # استایل سایت و پنل مدیریت (RTL)
│   ├── js/              # اسکریپت‌های تعاملی
│   ├── fonts/           # فونت وزیرمتن
│   └── img/             # لوگو و آیکون‌ها
└── templates/
    ├── *.html           # قالب‌های سایت عمومی
    └── admin/           # قالب‌های پنل مدیریت
```

## بانک اطلاعاتی (SQLite)

| جدول | شرح |
|------|------|
| `settings` | تنظیمات سایت |
| `admin_users` | کاربران مدیریت |
| `services` | خدمات (روان‌درمانی، مشاوره، آموزش، سایر) |
| `centers` | مراکز استانی |
| `news` | اخبار و اطلاعیه‌ها |
| `faqs` | سوالات متداول |
| `testimonials` | نظرات مراجعین |
| `bookings` | درخواست‌های نوبت مشاوره |
| `cooperation_requests` | درخواست‌های همکاری |
| `contact_messages` | پیام‌های تماس با ما |
| `feedbacks` | پیشنهادها و انتقادها |

## پشته فناوری

- **بکاند:** Python 3.10+ / Flask 3
- **دیتابیس:** SQLite (بدون نیاز به سرور جداگانه)
- **فرانت‌اند:** HTML5 / CSS3 / Vanilla JS — قالب‌های Jinja2
- **احراز هویت:** Session + Werkzeug PBKDF2
