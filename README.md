## امکانات

### بخش عمومی سایت
- صفحه اصلی با تمام بخش‌های سایت اصلی: خدمات، معرفی مرکز، انواع مشاوره، مشاوره تلفنی و آنلاین، روان‌درمانی، دریافت نوبت، آموزش، نظرات مراجعین، سوالات متداول
- 🧱 **بلوک‌های داینامیک صفحه اصلی** — مدیر می‌تواند از پنل، هر آیتم/فرم/مقاله/دوره/خدمت را به صفحه اصلی اضافه، ویرایش، مرتب یا مخفی کند (بخش «برگزیده‌ها»)
- 👤 **سیستم حساب کاربری**:
  - ثبت‌نام (`/register/`) و ورود (`/login/`) کاربران با کپچا و CSRF
  - **پنل کاربری** (`/panel/`) — مشاهده درخواست‌های مشاوره و ثبت‌نام‌های دوره با وضعیت + ویرایش پروفایل و گذرواژه
  - اتصال خودکار درخواست‌های ثبت‌شده به حساب کاربری
- صفحات خدمات: **روان درمانی**، **مشاوره**، **آموزش**، **سایر خدمات** + صفحه فهرست خدمات
- صفحه **مراکز استانی** با داده‌های واقعی ۳۱ استان (آدرس، تلفن کلینیک، مدیر، مسئول اجرایی، ساعت کاری) + جستجو
- 🤝 **فراخوان همکاری کامل (۴ مرحله‌ای)** مطابق فرم رسمی مجموعه — با **تم رزِ سایت** (هم‌سو با هویت بصری rosecenter):
  - مرحله ۱: مشخصات فردی (نام، کد ملی با **اعتبارسنجی زنده**، تاریخ تولد با **تقویم شمسی**، جنسیت، وضعیت سربازی)
  - مرحله ۲: مدارک (کارت ملی، مدرک تحصیلی، پروانه، مالکیت مرکز) — **آپلود فایل** (تصویر/PDF حداکثر ۵۰ کیلوبایت، Drag & Drop)
  - مرحله ۳: مشخصات مرکز (استان/شهرستان زنجیره‌ای، تلفن، کد پستی، نشانی، تعداد اتاق‌ها و مشاورین)
  - مرحله ۴: خلاصه اطلاعات + **کپچا** + پذیرش قوانین
  - صدور کد پیگیری `HR-` و ذخیره فایل‌ها روی سرور
- 🎓 **بخش دوره‌های آموزشی به سبک LMS مدرن (مانند مکتب‌خونه/فرادرس و سایت روان‌بُنه)**:
  - تب‌های فیلتر با شمارنده زنده: همه دوره‌ها / در حال ثبت‌نام / در حال برگزاری / پرمخاطب‌ترین / رایگان / دوره‌های ویژه
  - فیلتر بر اساس **دسته‌بندی دوره** (منوی کشویی) و جستجو در عنوان/خلاصه/مدرس
  - کارت‌های دوره با نشان وضعیت، قیمت (رایگان / ویژه)، تعداد ثبت‌نام، امتیاز و مدرس
  - **دسته‌بندی‌های دوره** با آیکون در منوی اصلی سایت و صفحه دوره‌ها
  - صفحه جزئیات دوره + فرم **ثبت‌نام دوره** (کد ملی معتبر، موبایل، **کپچا**) و صدور کد پیگیری `CRS-`
  - نمایش «تکمیل ظرفیت» به‌صورت خودکار
- 💬 **انجمن‌های تخصصی (فروم)** مانند سایت روان‌بُنه:
  - دسته‌بندی‌های انجمن با آیکون و شمارنده تاپیک/پاسخ
  - ساخت **تاپیک جدید** (فقط کاربران لاگین‌شده) + پاسخ دادن به تاپیک‌ها
  - صفحه‌بندی تاپیک‌ها، شمارش بازدید، آخرین فعالیت
  - مدیریت کامل از پنل ادمین: دسته‌ها (ایجاد/ویرایش)، تاپیک‌ها (سنجاق/قفل/نمایش/حذف)، پاسخ‌ها (نمایش/حذف)
- 🤖 **چت هوشمند آنلاین** (دستیار مجازی رز):
  - پاسخ خودکار به سوالات مرتبط با سایت و برنامه‌ها بر اساس **پایگاه دانش**
  - ۱۳ قاعده هدایت (Intent) برای راهنمایی و هدایت کاربر به صفحه مناسب با **دکمه‌های لینک**
  - رابط چت شناور در تمام صفحات + صفحه اختصاصی چت (`/chat/`)
  - ثبت کامل لاگ سوال/پاسخ برای بررسی مدیریت
- 🗓 **تبدیل تاریخ شمسی ↔ میلادی** با الگوریتم دقیق (کبیسه‌های واقعی مانند ۱۴۰۳) + روز هفته + **API عمومی JSON** + نمایش تاریخ امروز در بالای همه صفحات
- 🗺 **نقشه تعاملی ایران — مراکز و کلینیک‌ها**:
  - نمایش همه مراکز روی **نقشه Leaflet** با توایل OpenStreetMap + نشانگرهای دسته‌بندی (فایل‌های Leaflet به‌صورت آفلاین در پروژه باندل شده‌اند)
  - کلیک روی نشانگر → پاپ‌آپ نام، نوع، آدرس، تلفن و توانمندی‌های مرکز
  - فیلتر بر اساس نوع مرکز (مرکز/کلینیک) + فهرست کنار نقشه با لینک به صفحه جزئیات
- ➕ **ثبت مرکز / کلینیک جدید** (`/centers/register/`): فرم کامل با مختصات نقشه (انتخاب لوکیشن روی نقشه)، توانمندی‌ها و اطلاعات تماس — پس از تأیید مدیر روی نقشه نمایش داده می‌شود
- 👥 **معرفی اعضای هیئت مدیره** (`/board/`): تصویر، سمت، بیوگرافی و توانمندی‌های هر عضو + مدیریت از پنل
- سیستم **اخبار و اطلاعیه‌ها** با صفحه جزئیات، صفحه‌بندی و جستجو
- صفحات **درباره ما** و **تماس با ما** (با فرم تماس)
- صفحه **درخواست مشاوره** (فرم دریافت نوبت روان‌درمانی با انتخاب نوع درمان و مرکز) + کد پیگیری `RC-`
- صفحه **پیگیری درخواست** — پشتیبانی از هر ۴ نوع کد: نوبت (`RC-`)، همکاری قدیم (`HR-`)، **فراخوان همکاری جدید (`HR-`)** و **ثبت‌نام دوره (`CRS-`)**
- صفحه **پیشنهاد و انتقاد**
- **جستجوی سراسری** در خدمات، اخبار، سوالات متداول و مراکز
- کاملاً **RTL** و فارسی با فونت وزیرمتن (باندل‌شده در پروژه)
- واکنش‌گرا (Responsive) برای موبایل، تبلت و دسکتاپ + منوی موبایل
- فرم‌های محافظت‌شده با **CSRF Token** و **کپچا**

### پنل مدیریت (`/admin/`)
- ورود امن با گذرواژه هش‌شده (PBKDF2)
- **داشبورد** با آمار کامل (نوبت‌ها، فراخوان‌ها، ثبت‌نام دوره‌ها، پیام‌ها، کاربران، آنلاین‌ها، فراخوانی‌های API) + فهرست کاربران آنلاین هم‌اکنون
- 👥 **مدیریت کاربران سایت**: ایجاد، ویرایش، جستجو، فعال/غیرفعال‌سازی (با بستن خودکار سشن‌ها)، حذف
- 🟢 **افراد لاگین‌شده**: نمایش سشن‌های فعال با نوع (کاربر/مدیر)، نام، IP، مرورگر، زمان ورود و آخرین حضور + نشانگر «آنلاین» (۵ دقیقه اخیر) + **خروج اجباری** کاربر + تاریخچه سشن‌ها
- 🧱 **بلوک‌های صفحه اصلی**: افزودن هر آیتم سفارشی / فرم / مقاله / دوره / خدمت به صفحه اصلی + ترتیب‌دهی (▲▼) + نمایش/مخفی + حذف
- 🔑 **کلیدهای API**: ساخت کلید برای سامانه‌های خارجی، فعال/غیرفعال، آمار فراخوانی، حذف
- 🧩 **مستندات API** درون پنل با مثال cURL و کدهای خطا
- 🤖 **مدیریت چت هوشمند**:
  - CRUD **مستندات پایگاه دانش** (عنوان، محتوا، کلیدواژه‌ها، اولویت، لینک هدایت + برچسب لینک) — چت بر اساس این مستندات پاسخ می‌دهد
  - مشاهده **لاگ گفتگوها** (سوال، پاسخ، امتیاز تطابق، پاسخ داده‌شده/نشده) برای بهبود پاسخ‌ها
- مدیریت **درخواست‌های نوبت**: جستجو، فیلتر وضعیت، تغییر وضعیت، یادداشت مدیر، حذف + نمایش **منبع درخواست** (وب‌سایت / API)
- مدیریت **فراخوان‌های همکاری**: مشاهده تمام ۳۰+ فیلد + **دانلود ۷ نوع فایل پیوست** + تغییر وضعیت + حذف (با حذف فایل‌ها)
- مدیریت **دوره‌های آموزشی**: ایجاد، ویرایش، فعال/غیرفعال، حذف + **مدیریت دسته‌بندی‌های دوره**
- مدیریت **انجمن‌ها**: دسته‌بندی‌ها، تاپیک‌ها (سنجاق/قفل/مخفی)، پاسخ‌ها
- مدیریت **ثبت‌نام‌های دوره**: جستجو، تغییر وضعیت، یادداشت، حذف
- مدیریت **پیام‌های تماس** و **پیشنهادها و انتقادها** (خوانده‌شده/نشده، حذف)
- CRUD کامل **اخبار** (ایجاد، ویرایش، انتشار/عدم انتشار، حذف)
- CRUD کامل **مراکز استانی** + مدیریت **مراکز ثبت‌شده کاربران** (تأیید/رد برای نمایش روی نقشه) + **اعضای هیئت مدیره**
- CRUD کامل **سوالات متداول** و **نظرات مراجعین**
- مدیریت **خدمات** (نمایش/مخفی، ترتیب منو)
- **تنظیمات سایت** (تلفن‌ها، آدرس، ایمیل، شبکه‌های اجتماعی، متن فوتر)
- تغییر **گذرواژه مدیر**

### REST API (برای ارتباط سایر سامانه‌ها)
- ثبت درخواست مشاوره از سامانه‌های خارجی با احراز هویت **کلید API** (هدر `X-API-Key` یا `Authorization: Bearer`)
- استعلام وضعیت با کد پیگیری، فهرست درخواست‌ها با صفحه‌بندی، متادیتا (نوع‌های درمان و مراکز)
- مستندات کامل و نمونه کد در بخش [REST API](#rest-api-برای-سامانه‌های-خارجی) و درون پنل ادمین (`/admin/api-docs`)

## راه‌اندازی روی کامپیوتر شخصی

### پیش‌نیازها
- **Python نسخه ۳.۹ یا بالاتر** — از [python.org/downloads](https://www.python.org/downloads/) دانلود کنید.
  - ⚠️ هنگام نصب در ویندوز حتماً گزینه **«Add Python to PATH»** را تیک بزنید.

### ۱) دانلود پروژه از گیت‌هاب

**روش اول — با Git (پیشنهادی):**
```bash
git clone https://github.com/sjalilvand/rosecenter.git
cd rosecenter
```
> اگر Git ندارید، از [git-scm.com/downloads](https://git-scm.com/downloads) نصب کنید.
> در ویندوز می‌توانید بعد از نصب Git، در پوشه دلخواه **راست‌کلیک → Git Bash Here** بزنید و دستور بالا را اجرا کنید.

**روش دوم — بدون Git (دانلود ZIP):**
1. به [github.com/sjalilvand/rosecenter](https://github.com/sjalilvand/rosecenter) بروید.
2. دکمه سبز **«Code»** → **«Download ZIP»**.
3. فایل ZIP را در پوشه دلخواه باز (Extract) کنید.
4. یک **ترمینال/Command Prompt** باز کنید و به پوشه پروژه بروید:
   - ویندوز: `cd C:\Users\نام‌شما\Downloads\rosecenter-main`

### ۲) ساخت محیط مجازی و نصب پیش‌نیازها

**ویندوز (PowerShell یا CMD):**
```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
> اگر در PowerShell خطای مجوز گرفتید، اول این را اجرا کنید:
> `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`

**لینوکس / مک:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### ۳) اجرای پروژه

```bash
# ۱) ساختن دیتابیس و درج داده‌های اولیه (فقط بار اول)
python seed_data.py

# ۲) اجرای سرور
python app.py
```

سپس در مرورگر باز کنید: **http://127.0.0.1:5000**

- سایت: `http://127.0.0.1:5000`
- پنل مدیریت: `http://127.0.0.1:5000/admin/`
- ورود کاربران: `http://127.0.0.1:5000/login/`
- فراخوان همکاری: `http://127.0.0.1:5000/cooperation/`
- آکادمی و دوره‌ها: `http://127.0.0.1:5000/academy/`
- تبدیل تاریخ: `http://127.0.0.1:5000/jalali/`
- پیگیری درخواست: `http://127.0.0.1:5000/tracking/`
- کنترل سلامت: `http://127.0.0.1:5000/api/health`

## REST API برای سامانه‌های خارجی

سامانه‌های دیگر (بیمه، سازمان‌ها، وب‌سایت‌های همکار) می‌توانند با **کلید API** برای کاربرانشان درخواست مشاوره ثبت کنند. کلید را از پنل ادمین → «کلیدهای API» بسازید.

**احراز هویت** — در همه درخواست‌ها یکی از دو هدر:
```
X-API-Key: rc_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Authorization: Bearer rc_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

**۱) ثبت درخواست مشاوره:**
```bash
curl -X POST http://127.0.0.1:5000/api/v1/consultations \
  -H "Content-Type: application/json" \
  -H "X-API-Key: rc_xxxxxxxx" \
  -d '{"full_name":"سارا محمدی","phone":"09123456789","service_type":"زوج‌درمانی","center":"تهران"}'
```
پاسخ موفق (201):
```json
{"ok": true, "tracking_code": "RC-XXXXXXXX", "status": "در انتظار بررسی"}
```

**۲) استعلام وضعیت:** `GET /api/v1/consultations/RC-XXXXXXXX`

**۳) فهرست درخواست‌ها:** `GET /api/v1/consultations?limit=20&offset=0&status=در انتظار بررسی`

**۴) متادیتا:** `GET /api/v1/meta/services` (نوع‌های درمان مجاز + مراکز فعال)

**۵) سلامت اتصال:** `GET /api/v1/ping`

کدهای خطا: `401` کلید نامعتبر/ناقص، `403` کلید غیرفعال، `400` خطای اعتبارسنجی (`invalid_phone`، `invalid_service_type`، ...)، `404` کد پیگیری یافت نشد.

مستندات کامل درون پنل: `http://127.0.0.1:5000/admin/api-docs`

### ۵) به‌روزرسانی نسخه جدید

```bash
cd rosecenter
git pull        # اگر با ZIP دانلود کرده‌اید، دوباره ZIP جدید را دانلود کنید
pip install -r requirements.txt
python app.py
```
> دیتابیس `rose.db` شما دست‌نخورده باقی می‌ماند؛ جداول جدید در اولین اجرا به‌صورت خودکار ساخته می‌شوند.

### ۶) رفع اشکالات رایج

| مشکل | راه‌حل |
|------|--------|
| `python` شناخته نشد | در ویندوز به‌جای `python` از `py` استفاده کنید: `py -m venv venv` |
| `pip install` خطای مجوز | مطمئن شوید `venv` فعال است (اول دستور activate را بزنید) |
| پورت ۵۰۰۰ اشغال است | `set PORT=5001` (ویندوز) یا `export PORT=5001` (لینوکس/مک) و دوباره `python app.py` |
| PowerShell اجرای activate را اجازه نمی‌دهد | `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` |
| صفحات خالی / خطای ۵۰۰ | دیتابیس را حذف و دوباره بسازید: حذف `rose.db` و اجرای `python seed_data.py` |
| تصویر کپچا نمی‌آید | با کلیک روی خود تصویر، عبارت جدید بگیرید |

## نکات امنیتی استقرار واقعی
- متغیر محیطی `SECRET_KEY` را حتماً تنظیم کنید: `export SECRET_KEY="یک-رشته-تصادفی-بلند"`
- برای انتشار عمومی از `gunicorn` استفاده کنید: `gunicorn -w 2 -b 0.0.0.0:8000 app:app`
- پوشه `uploads/` و فایل `rose.db` را در بکاپ‌های دوره‌ای حفظ کنید.
