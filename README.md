## امکانات

### بخش عمومی سایت
- صفحه اصلی با تمام بخش‌های سایت اصلی: خدمات، معرفی مرکز، انواع مشاوره، مشاوره تلفنی و آنلاین، روان‌درمانی، دریافت نوبت، آموزش، نظرات مراجعین، سوالات متداول
- صفحات خدمات: **روان درمانی**، **مشاوره**، **آموزش**، **سایر خدمات** + صفحه فهرست خدمات
- صفحه **مراکز استانی** با داده‌های واقعی ۳۱ استان (آدرس، تلفن کلینیک، مدیر، مسئول اجرایی، ساعت کاری) + جستجو
- 🤝 **فراخوان همکاری کامل (۴ مرحله‌ای)** مطابق فرم رسمی مجموعه:
  - مرحله ۱: مشخصات فردی (نام، کد ملی با **اعتبارسنجی زنده**، تاریخ تولد با **تقویم شمسی**، جنسیت، وضعیت سربازی)
  - مرحله ۲: مدارک (کارت ملی، مدرک تحصیلی، پروانه، مالکیت مرکز) — **آپلود فایل** (تصویر/PDF حداکثر ۵۰ کیلوبایت، Drag & Drop)
  - مرحله ۳: مشخصات مرکز (استان/شهرستان زنجیره‌ای، تلفن، کد پستی، نشانی، تعداد اتاق‌ها و مشاورین)
  - مرحله ۴: خلاصه اطلاعات + **کپچا** + پذیرش قوانین
  - **۵ تم رنگی + حالت شب/روز**، صدور کد پیگیری `HR-` و ذخیره فایل‌ها روی سرور
- 🎓 **آکادمی رز با ثبت‌نام آنلاین دوره‌ها**:
  - لیست دوره‌ها با قیمت، مدرس، ظرفیت، زمان‌بندی و سطح
  - صفحه جزئیات دوره + فرم **ثبت‌نام دوره** (کد ملی معتبر، موبایل، **کپچا**) و صدور کد پیگیری `CRS-`
  - نمایش «تکمیل ظرفیت» به‌صورت خودکار
- 🗓 **تبدیل تاریخ شمسی ↔ میلادی** با الگوریتم دقیق (کبیسه‌های واقعی مانند ۱۴۰۳) + روز هفته + **API عمومی JSON** + نمایش تاریخ امروز در بالای همه صفحات
- سیستم **اخبار و اطلاعیه‌ها** با صفحه جزئیات، صفحه‌بندی و جستجو
- صفحات **درباره ما** و **تماس با ما** (با فرم تماس)
- صفحه **درخواست مشاوره** (فرم دریافت نوبت روان‌درمانی با انتخاب نوع درمان و مرکز) + کد پیگیری `RC-`
- صفحه **پیگیری درخواست** — پشتیبانی از هر ۴ نوع کد: نوبت (`RC-`)، همکاری قدیم (`HR-`)، **فراخوان همکاری جدید (`HR-`)** و **ثبت‌نام دوره (`CRS-`)**
- صفحه **پیشنهاد و انتقاد**
- **جستجوی سراسری** در خدمات، اخبار، سوالات متداول و مراکز
- کاملاً **RTL** و فارسی با فونت وزیرمتن (باندل‌شده در پروژه)
- واکنش‌گرا (Responsive) برای موبایل، تبلت و دسکتاپ + منوی موبایل
- فرم‌های محافظت‌شده با **CSRF Token** و **کپچا**

### پنل مدیریت (`/admin/`)
- ورود امن با گذرواژه هش‌شده (PBKDF2)
- **داشبورد** با آمار کامل (نوبت‌ها، فراخوان‌ها، ثبت‌نام دوره‌ها، پیام‌ها) و آخرین موارد
- مدیریت **درخواست‌های نوبت**: جستجو، فیلتر وضعیت، تغییر وضعیت، یادداشت مدیر، حذف
- مدیریت **فراخوان‌های همکاری**: مشاهده تمام ۳۰+ فیلد + **دانلود ۷ نوع فایل پیوست** + تغییر وضعیت + حذف (با حذف فایل‌ها)
- مدیریت **دوره‌های آموزشی**: ایجاد، ویرایش، فعال/غیرفعال، حذف
- مدیریت **ثبت‌نام‌های دوره**: جستجو، تغییر وضعیت، یادداشت، حذف
- مدیریت **پیام‌های تماس** و **پیشنهادها و انتقادها** (خوانده‌شده/نشده، حذف)
- CRUD کامل **اخبار** (ایجاد، ویرایش، انتشار/عدم انتشار، حذف)
- CRUD کامل **مراکز استانی**
- CRUD کامل **سوالات متداول** و **نظرات مراجعین**
- مدیریت **خدمات** (نمایش/مخفی، ترتیب منو)
- **تنظیمات سایت** (تلفن‌ها، آدرس، ایمیل، شبکه‌های اجتماعی، متن فوتر)
- تغییر **گذرواژه مدیر**

## راه‌اندازی روی کامپیوتر شخصی

### پیش‌نیازها
- **Python نسخه ۳.۹ یا بالاتر** — از [python.org/downloads](https://www.python.org/downloads/) دانلود کنید.
  - ⚠️ هنگام نصب در ویندوز حتماً گزینه **«Add Python to PATH»** را تیک بزنید.

### ۱) دانلود پروژه از گیت‌هاب

**روش اول — با Git (پیشنهادی):**
```bash
git clone https://github.com/sjalilvand/rosecenter.git
cd rosecenter
```
> اگر Git ندارید، از [git-scm.com/downloads](https://git-scm.com/downloads) نصب کنید.
> در ویندوز می‌توانید بعد از نصب Git، در پوشه دلخواه **راست‌کلیک → Git Bash Here** بزنید و دستور بالا را اجرا کنید.

**روش دوم — بدون Git (دانلود ZIP):**
1. به [github.com/sjalilvand/rosecenter](https://github.com/sjalilvand/rosecenter) بروید.
2. دکمه سبز **«Code»** → **«Download ZIP»**.
3. فایل ZIP را در پوشه دلخواه باز (Extract) کنید.
4. یک **ترمینال/Command Prompt** باز کنید و به پوشه پروژه بروید:
   - ویندوز: `cd C:\Users\نام‌شما\Downloads\rosecenter-main`

### ۲) ساخت محیط مجازی و نصب پیش‌نیازها

**ویندوز (PowerShell یا CMD):**
```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
> اگر در PowerShell خطای مجوز گرفتید، اول این را اجرا کنید:
> `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`

**لینوکس / مک:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### ۳) اجرای پروژه

```bash
# ۱) ساختن دیتابیس و درج داده‌های اولیه (فقط بار اول)
python seed_data.py

# ۲) اجرای سرور
python app.py
```

سپس در مرورگر باز کنید: **http://127.0.0.1:5000**

- سایت: `http://127.0.0.1:5000`
- پنل مدیریت: `http://127.0.0.1:5000/admin/`
- فراخوان همکاری: `http://127.0.0.1:5000/cooperation/`
- آکادمی و دوره‌ها: `http://127.0.0.1:5000/academy/`
- تبدیل تاریخ: `http://127.0.0.1:5000/jalali/`
- پیگیری درخواست: `http://127.0.0.1:5000/tracking/`
- کنترل سلامت: `http://127.0.0.1:5000/api/health`

### ۴) ورود به پنل مدیریت

| نام کاربری | گذرواژه |
|-----------|---------|
| `admin` | `rose@1403` |

> ⚠️ بعد از ورود، از بخش «تنظیمات» گذرواژه را عوض کنید.

### ۵) به‌روزرسانی نسخه جدید

```bash
cd rosecenter
git pull        # اگر با ZIP دانلود کرده‌اید، دوباره ZIP جدید را دانلود کنید
pip install -r requirements.txt
python app.py
```
> دیتابیس `rose.db` شما دست‌نخورده باقی می‌ماند؛ جداول جدید در اولین اجرا به‌صورت خودکار ساخته می‌شوند.

### ۶) رفع اشکالات رایج

| مشکل | راه‌حل |
|------|--------|
| `python` شناخته نشد | در ویندوز به‌جای `python` از `py` استفاده کنید: `py -m venv venv` |
| `pip install` خطای مجوز | مطمئن شوید `venv` فعال است (اول دستور activate را بزنید) |
| پورت ۵۰۰۰ اشغال است | `set PORT=5001` (ویندوز) یا `export PORT=5001` (لینوکس/مک) و دوباره `python app.py` |
| PowerShell اجرای activate را اجازه نمی‌دهد | `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` |
| صفحات خالی / خطای ۵۰۰ | دیتابیس را حذف و دوباره بسازید: حذف `rose.db` و اجرای `python seed_data.py` |
| تصویر کپچا نمی‌آید | با کلیک روی خود تصویر، عبارت جدید بگیرید |

## ساختار پوشه‌ها

```
rosecenter/
├── app.py              # تمام روت‌های فلسک (سایت + ادمین + API)
├── database.py         # لایه دیتابیس SQLite (ساخت جداول + کوئری)
├── jalali.py           # تبدیل تاریخ شمسی ↔ میلادی (الگوریتم دقیق)
├── config.py           # تنظیمات، تلفن‌ها، انواع درمان
├── seed_data.py        # داده‌های اولیه (خدمات، مراکز، اخبار، دوره‌ها...)
├── requirements.txt    # پیش‌نیازها (فقط Flask!)
├── README.md
├── templates/          # ۲۵+ قالب سایت و پنل مدیریت
│   ├── base.html, home.html, cooperation.html (فراخوان ۴ مرحله‌ای)
│   ├── academy.html, course_detail.html, course_register.html
│   ├── jalali.html, ...
│   └── admin/ (داشبورد، فراخوان‌ها، دوره‌ها، ثبت‌نام‌ها، ...)
├── static/             # CSS، JS، فونت وزیرمتن، لوگو
├── uploads/            # فایل‌های آپلودی فراخوان همکاری (خودکار ساخته می‌شود)
└── rose.db             # دیتابیس (خودکار ساخته می‌شود — در گیت ذخیره نمی‌شود)
```

## نکات امنیتی استقرار واقعی
- متغیر محیطی `SECRET_KEY` را حتماً تنظیم کنید: `export SECRET_KEY="یک-رشته-تصادفی-بلند"`
- برای انتشار عمومی از `gunicorn` استفاده کنید: `gunicorn -w 2 -b 0.0.0.0:8000 app:app`
- پوشه `uploads/` و فایل `rose.db` را در بکاپ‌های دوره‌ای حفظ کنید.
