🧩 مستندات REST API — نسخه v1

این API به سامانه‌های خارجی (بیمه‌ها، سازمان‌ها، وب‌سایت‌های همکار و...) اجازه می‌دهد برای کاربران خود درخواست مشاوره ثبت کنند و وضعیت درخواست را استعلام کنند. کلیدها را از صفحه کلیدهای API بسازید.

۱) احراز هویت

در تمام درخواست‌ها یکی از دو هدر زیر را ارسال کنید:

X-API-Key: rc_xxxxxxxxxxxxxxxxxxxxxxxx
Authorization: Bearer rc_xxxxxxxxxxxxxxxxxxxxxxxx

۲) بررسی سلامت اتصال

GET /api/v1/ping
→ { "ok": true, "service": "rosecenter-api", "version": "v1", "system": "نام سامانه شما" }

۳) ثبت درخواست مشاوره

POST /api/v1/consultations
Content-Type: application/json
X-API-Key: rc_xxxx...

{
  "full_name": "سارا محمدی",        (الزامی)
  "phone": "09123456789",          (الزامی — 10 تا 11 رقم)
  "service_type": "زوج‌درمانی",     (الزامی — از فهرست مقادیر مجاز)
  "center": "تهران",               (اختیاری)
  "note": "توضیحات کاربر"          (اختیاری)
}

→ 201 { "ok": true, "tracking_code": "RC-XXXXXXXX", "status": "در انتظار بررسی" }

مقادیر مجاز service_type: {% for t in THERAPY_TYPES %}{{ t }} {% endfor %}

۴) فهرست درخواست‌ها

GET /api/v1/consultations?limit=20&offset=0&status=در انتظار بررسی
→ { "ok": true, "total": 42, "limit": 20, "offset": 0, "items": [ ... ] }

۵) استعلام وضعیت با کد پیگیری

GET /api/v1/consultations/RC-XXXXXXXX
→ { "ok": true, "item": { "tracking_code": "RC-XXXXXXXX", "status": "در حال بررسی", ... } }

۶) متادیتا (نوع‌های درمان و مراکز فعال)

GET /api/v1/meta/services
→ { "ok": true, "service_types": [...], "statuses": [...], "centers": [...] }

📱 وب‌سرویس اپلیکیشن (نسخه جدید — مناسب اپ موبایل Rose)

این گروه از مسیرها برای اپلیکیشن موبایل (مثل اپ «Rose Psychology») طراحی شده است؛ همه با همان کلید API احراز هویت می‌شوند.

۸) اطلاعات عمومی سایت

GET /api/v1/site
→ { "ok": true, "site_name", "phones", "email", "address",
    "instagram", "telegram", "whatsapp", "linkedin",
    "map": { "lat": 35.7626, "lng": 51.4737 },
    "service_types": [...], "statuses": [...] }

۹) خدمات، مراکز، دوره‌ها، اخبار و سوالات متداول (چندزبانه)

GET /api/v1/services?lang=fa
→ { "ok": true, "lang": "fa", "items": [ { "slug", "title", "subtitle", "summary", "icon" } ] }

GET /api/v1/centers?province=تهران&lang=en
→ { "ok": true, "lang": "en", "items": [ { "province", "clinic_name", "kind", "address", "clinic_phone",
                             "manager_name", "work_hours", "lat", "lng", "capabilities" } ] }

GET /api/v1/courses?limit=30&category=&q=&lang=ru
GET /api/v1/courses/<slug>?lang=ar
→ { "ok": true, "items": [ { "title", "teacher", "price", "duration", "capacity",
                             "start_date", "level", "status", "rating", "students", ... } ] }

GET /api/v1/news?limit=20&lang=zh
GET /api/v1/news/<slug>?lang=en
→ { "ok": true, "items": [ { "slug", "title", "summary", "category", "published_at", "views" } ] }

GET /api/v1/faqs?lang=ar
→ { "ok": true, "items": [ { "category", "question", "answer" } ] }

# چندزبانه: پارامتر اختیاری lang روی همه اندپوینت‌های محتوایی بالا
# مقادیر: fa (پیش‌فرض) | en | ar | ru | zh
# اگر ترجمه‌ای ثبت نشده باشد، همان متن پایه فارسی برگردانده می‌شود.
# ترجمه‌ها از پنل ادمین ← بخش «ترجمه محتوا» ثبت می‌شوند.

۱۰) ثبت نوبت کامل از اپ (با تاریخ و ساعت پیشنهادی)

POST /api/v1/bookings
Content-Type: application/json
X-API-Key: rc_xxxx...

{
  "full_name": "علی رضایی",
  "phone": "09123456789",
  "service_type": "درمان فردی",
  "center": "تهران",              (اختیاری)
  "note": "...",                  (اختیاری)
  "preferred_date": "1404/03/15", (اختیاری — شمسی)
  "preferred_time": "evening",    (اختیاری — morning/noon/evening/night)
  "lang": "fa"                    (اختیاری — fa/en/ar/ru/zh)
}

→ 201 { "ok": true, "tracking_code": "RC-XXXXXXXX", "status": "در انتظار بررسی" }

استعلام وضعیت: GET /api/v1/bookings/RC-XXXXXXXX — همان پاسخ مسیر consultations ولی شامل preferred_date و preferred_time.

۱۱) چت هوشمند چندزبانه از اپ

POST /api/v1/chat
Content-Type: application/json
X-API-Key: rc_xxxx...

{ "message": "چطور نوبت بگیرم؟", "locale": "fa", "session_key": "app-user-1" }
→ { "ok": true, "answer": "...", "links": [ { "label", "url" } ], "answered": true }

— locale مجاز: fa / en / ar / ru / zh (پاسخ به همان زبان تولید می‌شود)

۱۲) کدهای خطا

کد HTTPerror.codeتوضیح
401missing_api_keyهدر کلید ارسال نشده است
401invalid_api_keyکلید نامعتبر است
403inactive_api_keyکلید غیرفعال شده است
400missing_full_name / invalid_phone / missing_service_type / invalid_service_typeخطای اعتبارسنجی داده
404not_foundکد پیگیری یافت نشد
